THE ARCHITECTURAL SHIFT

Industrial Giants vs. DIY & Mini-Robotics

Classical robotics is designed for heavy, hazardous industrial arms. Mini-robotics requires an inverted set of engineering priorities.

Architectural Dimension Classical Industrial Robotics SeedCore DIY & Mini-Robotics
Physical Hazard Profile High mass (15–100+ kg), high torque (20–150+ Nm). Crushing & impact risk. Featherweight (< 500g – 2 kg), micro-torque (< 0.2–2 Nm). Inherent, passive mechanical safety.
Safety Paradigm Active Enforced Containment: C++ geofencing, optical light curtains, ISO force clamps. Safe-by-Physics: Motor stall torque cannot break skin. Passive compliance via 3D-printed PETG/TPU.
Compute & Power Envelope Heavy onboard SoCs (Jetson AGX Orin 60W+) or multi-GPU servers (8x H100s). Ultra-low power microcontrollers: ESP32, RP2040, STM32, or host laptops. 5V USB / 2S LiPo.
Communication Bus Industrial fieldbuses: CAN-FD (5 Mbps), EtherCAT (100 Mbps), MIPI CSI-2 DMA. Consumer serial & Web APIs: UART/RS-485 serial bus (1 Mbps), USB-CDC, WebSerial, BLE.
Simulation & Tooling Heavy Ubuntu workstation dependencies, complex ROS 2 setups, NVIDIA Isaac Sim. Browser-Native & Zero-Install: C++/Wasm simulation (ABI 1 & ABI 2), runs on any Chromebook/laptop.
Model Strategy Monolithic 7B–70B parameter generalist VLAs running on remote cloud clusters. Hierarchical Edge-Microbrains: Compact policies (ACT, Diffusion Policy) or cloud VLMs dispatching bounded action chunks.
Trust & Governance Rigid industrial PLC interlocks, closed proprietary firmware safety gates. SeedCore Verifiable Governance: Scoped capability tokens, signed receipts, parental/educator supervision.
Cost Profile $15,000 – $150,000+ per unit. $50 – $300 total Bill of Materials (BOM).

COMMUNICATION & LATENCY REALITY

The "Slow Brain, Fast Spine" Pattern

Mini-robots communicate over consumer serial/BLE with 15–40 ms of jitter. Instead of fighting jitter with expensive industrial transceivers, SeedCore adopts receding-horizon action chunking.

01 / SLOW BRAIN

Cloud / Host / Browser

Runs a compact policy or VLM planner at 10–20 Hz, dispatching a chunk of 30–50 future waypoints (0.5–1.0s horizon).

→
02 / SEEDCORE GATE

Scoped Capability Token

Policy Decision Point validates intent bounds, freshness, and safety limits. Issues signed revocable tokens.

→
03 / FAST SPINE

Edge MCU (ESP32 / RP2040)

Deterministic C++ spline interpolator running locally at 200–500 Hz executes smooth motor setpoints over UART bus servos.

→
04 / VERIFIABLE EVIDENCE

Cryptographic Receipts

Action-bound telemetry logs are hashed and verified against policy limits by the Rust proof engine (RESULT_VERIFIER).

COMPREHENSIVE TECH STACK

Engineered across every layer

From zero-allocation C++ dynamics to Rust verification and browser WebAssembly.

C++17 / CMake

Zero-Allocation Physics Kernel

Analytical kinematics and dynamics for 1-, 2-, and 3-link chains. Cramer cofactor 3x3 matrix inversion, skew-symmetric Coriolis vector, and RK4 integration in caller-owned memory.

  • ABI 1 Planar
  • ABI 2 Multi-Link Tree
  • No Malloc / No Exceptions
WebAssembly / LLVM

Dual-ABI Wasm Core

Compiled with Clang and wasm-ld into a compact 13 KB binary. Standalone host math imports (sin/cos) with zero dynamic linear memory growth, running at 480 Hz in the browser.

  • 13 KB Payload
  • 100% Deterministic
  • Chromebook Native
HTML5 / Canvas 3D

Zero-Install 3D Studio

Zero-dependency 3D perspective projection with interactive orbit controls (drag-to-orbit yaw/pitch, zoom). Live analytical inspectors for mass matrix M(q), Jacobian J(q), and mechanical energy.

  • Zero CDN Dependencies
  • Depth-Sorted Projection
  • JSON State Exporter
TypeScript / JSON Schema

Model Contracts & Schemas

Strict schemas (seedcore.mini-sim.tree-model.v1) with UTF-8 canonical JSON SHA-256 digests. Validates physical mass, link inertia, COM bounds, and forward kinematics in 3D.

  • Worker v2/v3 Protocol
